# 全跑道紅燈反彈觀察模式

適用A、B1、B2、B3與兩個B1比較模擬帳本。復用既有玉山本機指數、股票快照，沒有新增券商連線或訂閱。只影響研究與模擬新進場，不建立實單出口。

第一版固定門檻：加權、櫃買連續三段分鐘邊界價格回升，合計至少0.25%；共同股票樣本最近三分鐘成交股數速率至少是前一個三分鐘的1.3倍，且至少55%股票價格回升。最少500檔、三個快照的共同樣本覆蓋率至少80%。這是近期相鄰時窗量能比較，不是假稱具有歷史同時段基準。

任一指數30秒跌0.15%、連續三段分鐘邊界價格下滑且合計跌0.10%、或反彈後加權從觀察高點回吐0.12%，封鎖所有跑道新進場，冷卻至少180秒。正常綠燈與黃燈也受下降檢查約束。缺行情、未來行情、過期行情不放行；即使剛允許進場，許可也最多有效3秒。這些門檻尚未以歷史收益調參或驗證。

有限放行時保留原跑道訊號、五檔、資格、成本與停損檢查，每個跑道最多一筆持倉、一張且金額最多10萬元，只開放做多；因此股價超過100元的整張股票不會進場。恢復紅燈代表停止新進場；已持有部位仍執行原本停損、停利與時間出場，不會關閉出場功能。

先累積至少六分鐘可用成交量快照與三段分鐘價格；重啟與換日重新暖機。沒有用今天已完成的走勢補出虛擬成交。每秒本機紀錄 `market-rebound-YYYY-MM-DD.jsonl`，每筆B交易標記 `market_entry_mode`，A保存 `entry_gate_evidence.rebound_guard`，供盤後分開評估有限放行交易與一般交易。

第一次前向觀察為10/16。這個模式不保證捕捉所有反彈，也不會自動訓練或晉升模型。
