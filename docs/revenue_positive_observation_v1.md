# 營收成長＋正向消息隔日觀察 v1

最新月營收年增、月增均 > 0，且資料年月距目前不超過兩個月，搭配七天內重大訊息中的明確正向文字。官方 TWSE／TPEx 月營收涵蓋上市櫃四位數普通股，不受首頁熱門股或價格限制。

正向文字：營收創新高或成長、獲利成長、轉虧為盈、訂單增加／取得訂單、上修展望；同句否定、衰退、下修、假設敘述及澄清公告排除。規則為保守的關鍵文字篩選，不等同人工確認或全文語意判斷。法說會行程、財報核准、未讀取的簡報與影片不自動視為利多。來源沿用 `market_events` 公告庫，保存來源名稱、公告日與首次取得時間，首頁提供觀測站查詢入口。

首次同時滿足條件時才建立訊號，保存當時營收、文字及取得時間。公告回補不會產生歷史績效。下一個交易日由既有市場行事曆推算，訊號成立日休市則基準價取前一交易日收盤。同股同觀察日只計一次，同一公告與營收月份不重複建立訊號。

完整官方日線在16:00後才採入，價格日期必須精確符合基準日／觀察日且有成交量。開盤、最高、最低、收盤均以基準收盤比較；另計開盤到收盤變動。缺少任一日行情不結算、不以零報酬代入。停牌、漏抓行情會持續顯示待補；目前無自動歷史行情補抓。突發休市若發生於目標日排定之後，需重新核對，不冒用其他日期。

SQLite 狀態位於既有事件資料目錄 `revenue-watch.sqlite`；JSON 位於 `revenue-watch-latest.json`，發布至 `/market_data/public_feed/revenue_observation`。每小時15分排程、頁面每10分鐘更新，延遲90分鐘提示。首頁顯示最新200筆，統計涵蓋所有紀錄。

這是前向觀察，沒有交易、限額、停損停利或新增通知；未計交易成本、股利／除權息調整，收盤上漲比例不是當沖勝率。多個不同訊號日的同股仍可能相關，平均漲幅不代表因果或策略有效性。v1不提供尚未累积完成的歷史勝率。
