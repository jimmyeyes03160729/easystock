# A 訊號價量與大盤學習

授權範圍：2026-10-14 使用者要求處理復盤發現的問題，並研究 A 未進入模擬帳戶訊號的獲利／虧損型態及大盤。

## 樣本與時間

每日只讀明確日期的 `research_trades`，來源資料庫以 SQLite `mode=ro` 開啟。
研究起始日固定 2026-10-14；不讀先前研究、封存 holdout 或未來日期。
未買進訊號仍納入；保留 paper skip reason，額度不足不等於訊號品質差。
只使用已結束且有成本與價差後結果的 episode；未結束／缺標籤不當成虧損。
去重以 episode ID 為單位，不重算每次雷達判斷。

## 特徵與結果隔離

保留既有五項進場特徵，另加入完成一分 K 的實體／上下影線／收盤位置、五分鐘報酬與振幅、最近兩組五分鐘量比、VWAP 距離。
大盤使用原有玉山指數快照，先檢查交易所時間、單筆接收時間、快照接收時間皆不晚於進場；再計算加權／櫃買五分鐘報酬。
缺行情保留 null，不補零。盤後一分 K 重建只做描述性比較，不冒充進場時真的可用的特徵。
進場引擎另保存當時已完成 K 棒的相同特徵、大盤時間與策略程式／出場參數指紋。
MFE、MAE、出場價、出場原因、是否買進與未買進原因只做結果分析，不進入模型向量。

## 重訓規則

候選學習只接受 2026-10-15 起、完整且有版本指紋的線上特徵；歷史重建不混入候選訓練。
至少 101 個獨立日期、1,000 筆完整樣本，每個訓練窗至少各 30 筆正／非正成本後結果。
固定三個依日期排列的 20 日驗證窗，訓練與驗證之間隔離一整天；當沖結果限定同日結束，因此不跨日期重疊。
標準化只擬合訓練窗。固定概率門檻 0.6，比較全部已成立 A 訊號，不比較只成交的資金受限子集。
校準基準使用訓練窗的正樣本比例，不能使用驗證窗事後比例。
候選模型只寫隔離報告，`approved=false`、`deployment_allowed=false`，不覆寫正式模型。
新的未使用前瞻期、資金／回撤模擬與線上影子比較完成前，不得晉升。

## 排程與操作

獨立 `easystock-a-signal-learning.timer` 在台灣工作日 14:30、17:00 跑唯讀來源的離線整理；不登入券商、不發通知、不下單。
輸出：`/home/ubuntu/easystock-a-signal-learning/datasets/日期.json`、`reports/日期.json`、`latest.json`。
手動重跑：`.venv/bin/python -m daytrade_learning.a_signal_learning --date 2026-10-14`。
