# 反彈模擬修正計畫（歷史資料複核）

日期：2026-10-08。修正識別碼：`REBOUND_SIMULATION_CORRECTION_V1`。
本計畫在修正結果計算前記錄；P2/P3/P4 的原始預登記、結果檔與決策保留。
這是已曝光資料的錯誤修正與描述性敏感度分析，不是新的獨立確認。

## 資料邊界

- 來源資料庫以 SQLite `mode=ro` 開啟。建立暫存歷史副本時，所有日期資料在 SQL 中限定 `< 2026-10-07`。
- 不複製或讀取 candidates 的 label 欄位；只複製上述日期的快照。
- 市場 bars、除權息、次日參考價與交易日曆也只複製上述日期。
- 後續重現與修正一律只使用歷史副本；封存資料不參與計算。
- `future_bars` 加上底層 SQL 日期上限，並限制在指定市場交易日持有期內。

## 固定修正

1. P2 保留所有 D0 合格候選，未來缺資料不得改變排名池。每個排名方案取前三名之後才判斷成交，空缺不遞補。
2. P2/P3/P4 共用交易日對齊的模擬器；缺 K 線以空值保留所在交易日，不把下一根 K 線誤當 D1。
3. D1 缺 K 線或開盤不在 bracket 內，列為未成交。持倉期間缺 K 線而尚未出場，列為 `UNRESOLVED_MISSING_BAR`，不可宣稱該交易不存在或報酬為零。
4. 已在缺 K 線之前出場的交易保留；D5 方案不受 D6～D20 缺資料影響。
5. 沿用 D1 開盤進場、D2 起跳空以開盤出場、盤中停損優先、固定期限收盤出場、0.6% 成本。保持原模型、特徵、排序、濾網、folds 與各研究的訊號成熟窗口。
6. 所有報告標示 correction ID、原始 preregistration ID、描述性用途與未解決交易數。不得將修正結果自動升格為正式推薦或解除保留期。

## 固定分析輸出

- 原始歷史結果的安全重現與雜湊核對（若原始結果可重現）。
- P2 四種排名、P3 四種出場、P4 兩段濾網的修正結果與原結果比較。
- 固定交易清單下的成本敏感度：0.60%、0.50%、0.45%、0.40%、0.30%；損益兩平成本等於平均毛報酬，不代表任何成本實際可達。
- 訊號日連續區塊 bootstrap 敏感度：10、20 個交易日；2,000 次、seed 0；fold 內抽樣，不跨 fold，包含無成交的訊號日。此分析不取代原預登記通過條件。
- 未解決交易的數量及使全部已成交與未解決交易合計淨均值達零所需的未解決交易平均報酬。這是代數門檻，不填入虛構成交價。
- 研究對象仍是還原價技術候選、不含歷史財務初篩。無法從本次結果直接推論首頁正式 PASSED 推薦。

## 保留期與既有曝光

本次不使用 `REBOUND_V2_FUTURE_60D`。底層無日期上限是潛在封存漏洞；
沒有原始 SQL 執行紀錄或當時資料庫快照，不能認定先前已發生曝光，也不能認定絕未曝光。
本次只記錄歷史重用。待修正與歷史診斷完成後，再評估新策略是否值得另行預登記。
