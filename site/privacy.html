隱私權政策 (Privacy Policy)

適用版本：Chrome 擴充功能 2.1 起　生效日期：2.1 於 Chrome 線上應用程式商店上架日

本隱私權政策適用於 Chrome 擴充功能「當沖吧！牛馬仔 - 工位摸魚看盤神器 ｜ 台股行情觀察」（以下簡稱「本擴充功能」）。2.0 新增「可選用的 Google 帳號登入與雲端同步」；2.1 新增「自選股到價提醒」與在您電腦上計算的「智慧參考價位」。以下說明我們實際處理哪些資料、為何處理，以及您如何控制。

重點摘要：不登入也能完整使用本機自選股與到價提醒。只有在您主動選擇「使用 Google 登入」後，我們才會以您的 Firebase 使用者 ID（UID）在 Firebase 儲存您的自選股、提醒條件、到價提醒價位與介面偏好，用於在不同電腦之間同步。我們不出售資料、不投放廣告，也不收集券商帳號或交易密碼。

1. 不登入時：資料只存在您的電腦

本擴充功能使用 Chrome 本機儲存空間（chrome.storage.local）保存：

  • 您設定的台股自選股清單與股票群組（如自選、當沖監控）。
  • 提醒條件（如價格區間、漲幅門檻、提醒開關）。
  • 到價提醒：您為自選股設定的上限／下限價、各自的啟用狀態、觸發方式與冷卻時間；以及只存在本機的觸發狀態（例如最後提醒時間），用來避免重複通知。
  • 介面偏好（白色／深色主題、紅綠／黑白漲跌配色、字級、列表高度、外部網站捷徑等）。
  • 公開行情的暫存（報價、指數），僅用於畫面顯示，不會上傳。

2. 選擇 Google 登入時：登入的用途

登入完全是選用的，唯一目的是讓您在不同電腦同步自選股與設定。登入流程使用 Chrome 內建的 chrome.identity 取得 Google 授權，再交由 Google 的 Firebase Authentication 驗證並產生 UID。我們請求的 Google 權限範圍僅限 openid、email、profile。

  • Firebase Authentication（Google 提供）：保存您的帳號識別資訊（UID、Google 帳號 Email、顯示名稱），用於確認是您本人。
  • 擴充功能本機：保存 UID、Email 與顯示名稱以便在設定頁顯示「目前登入帳號」；登入憑證（Firebase ID Token）只存在瀏覽器工作階段儲存區（chrome.storage.session），關閉瀏覽器即清除；我們不保存 Google 密碼、OAuth Client Secret 或長期 Refresh Token。

3. 雲端同步的資料種類

登入後，以下資料會儲存在 Firebase Realtime Database 的 users/{您的 UID} 底下，並受資料庫安全規則保護，只有您本人登入時可讀寫：

  • 自選股（代號、市場別、名稱、所屬群組、加入／更新時間；刪除時保留刪除時間標記，避免已刪除股票被其他電腦加回）。
  • 提醒條件與介面偏好（每個設定值與其更新時間）。
  • 到價提醒設定（股票代號、上限／下限價、啟用狀態、觸發方式、冷卻時間與更新時間；解除時保留刪除時間標記，避免被其他電腦加回）。
  • 同步用的技術欄位（資料格式版本、最後更新時間、用戶端類型）。

不會上傳：報價／K 線等公開行情暫存、到價提醒的觸發狀態與最後提醒時間、智慧參考價位的計算結果、VIP 授權雜湊、通知紀錄、任何登入權杖、券商帳號或交易資料。雲端資料中不另外儲存您的 Email（帳號資訊由 Firebase Authentication 管理）。

4. 自選股如何同步

  • 本機優先：新增或修改會先存在您的電腦並立即顯示，之後才以短連線上傳，不會為了同步建立長時間的即時連線。
  • 第一次登入時，本機既有資料與雲端資料「只合併、不覆蓋、不刪除」。
  • 之後每項資料以較新的修改為準；離線時的修改會保留並在連線恢復後補上傳。
  • 在同一台電腦切換成另一個 Google 帳號時，前一個帳號的資料不會上傳到新帳號。

5. 如何登出、停用同步與刪除雲端資料

  • 登出：擴充功能「設定 → Google 帳號同步 → 登出」。登出會清除本機登入憑證並停止同步；雲端資料保留，本機自選仍可離線使用。
  • 撤銷 Google 授權：可隨時至 Google 帳戶「第三方應用程式與服務」移除本擴充功能的存取權。
  • 刪除雲端資料：請透過下方聯絡方式提出，註明登入時使用的 Google 帳號 Email；我們會在確認身分後刪除該帳號在 users/{UID} 下的資料與 Firebase Authentication 帳號，並回覆完成。請勿在公開 Issue 張貼個人資料，可要求改以私訊聯繫。
  • 移除擴充功能會一併刪除本機資料（雲端資料需依上述方式刪除）。

6. 外部網路連線

  • 公開行情（唯讀）：mis.twse.com.tw、Yahoo 奇摩股市／Yahoo Finance、EasyStock 公開發布端（GitHub、Firebase market_data）。查詢公開行情時只送出股票代號。
  • 登入與同步（僅在您登入後）：Google OAuth（chrome.identity）、Firebase Authentication（identitytoolkit.googleapis.com）、Firebase Realtime Database（easystock-c237a-default-rtdb.firebaseio.com）。
  • 到價提醒與智慧參考價位：到價提醒由擴充功能在背景以上述公開行情檢查，並以 Chrome 系統通知顯示；智慧參考價位只在您按下按鈕時，以 Yahoo Finance 公開日 K 在您的電腦上用技術指標計算。兩者都不會把您的資料送往任何 AI 或第三方分析服務，也不會產生任何券商委託。

  • 我們不向任何第三方出售、出租或交換使用者資料，不用於廣告、信用評估或貸款審核。
  • 本擴充功能對使用者資料的使用遵守 Chrome Web Store 使用者資料政策，包括「有限使用」（Limited Use）要求。
