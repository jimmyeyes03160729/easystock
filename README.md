# easystock / 墨衡量化 Mohren Quant Matrix v1.1

台股「無腦選股」量化儀表板。首頁採 **先給答案、再看理由**：市場燈號 → 今日首選 TOP 3 → 當沖 / 隔日衝 → 短波段 / 長期核心。

> 本專案為資料整理與量化研究用途，不構成投資建議。

## v1.1 重點

- **當沖 TOP 3**：Fugle 5 分 K 為主，程式自行聚合 15 分 K，交叉確認趨勢、VWAP、量能、突破、日 K 與市場燈號。
- **隔日衝 TOP 3**：重視尾盤 30 分鐘、15 分 K 趨勢、收盤位置、量價、法人與日 K；尾盤轉弱、長上影、跌破 VWAP 會降級或淘汰。
- **不硬湊名單**：未達最低線型門檻時直接顯示「今日無推薦」。
- **否決條件**：跌破 VWAP、距 VWAP 過遠、末根長上影、5 分 K 破短低、市場紅燈。
- **首頁取消模型可信度區塊**：完整回測仍保留在後端與個股詳情，不再佔首頁版面。
- **今日市場燈號**：依熱門股票池的均線多頭比例與 20 日平均動能分為正常 / 保守 / 觀望。
- **今日首選 TOP 3**：只從回踩、主升與長期策略挑選，不再把舊的日線短線代理混入主推薦。
- **快速價格帶 / 單張預算**：所有目前推薦區塊都會套用使用者設定。

## 短打線型交叉邏輯

### 當沖

主要權重：

- 5 分 K / 15 分 K 趨勢與高低點墊高
- VWAP 位置與距離
- 最近量能放大
- 早盤區間突破或壓縮後放量突破
- 大盤市場燈號
- 成交金額流動性
- 既有日線隔日代理回測只作小權重確認

### 隔日衝

主要權重：

- 尾盤 30 分鐘強度
- 15 分 K 趨勢
- 收盤接近日高
- 量能配合
- 成交金額流動性
- 15 日法人方向
- 日 K 趨勢

## 資料來源

### TWSE / TPEx 官方公開資料

負責每日 OHLCV、成交金額、估值、月營收、財報、法人、股利。

### Fugle

負責：

- 3–5 年歷史 K 線研究
- 歷史缺口補齊
- 盤中 5 分 K 線型掃描

Fugle Key 放在 GitHub Actions Secret：

```text
FUGLE_API_KEY
```

不要把 API Key 寫進公開程式碼。

## GitHub Actions

### Daily Stock Data Update

平日台灣時間 15:30 更新官方行情、基本面、法人與 rolling-forward 驗證。

### Intraday & Overnight Picks

平日預定在台灣時間：

```text
09:30
10:00
11:00
12:00
13:00
13:20
```

每次先從熱門股票池篩約 30 檔高流動性候選，再抓 Fugle 5 分 K；15 分 K 由程式本地聚合，降低 API 呼叫量。

> GitHub Actions 的 cron 屬排程服務，實際啟動時間可能有數分鐘延遲，因此本功能是盤中掃描，不是券商級逐秒訊號。

### Historical Research Backfill (Fugle)

第一次部署建議手動執行 3 年 / 500 檔；需要更多市場循環再做 5 年。

## 使用順序

1. 先看市場燈號；紅燈可直接觀望。
2. 設價格區間或單張預算。
3. 盤中看 **當沖 TOP 3**。
4. 接近尾盤看 **隔日衝 TOP 3**；13:20 的掃描最有參考性。
5. 非短打需求再看今日首選、短波段、長期核心。

## 重要限制

- 當沖 / 隔日衝為規則式線型篩選，不代表保證獲利或實際成交建議。
- 目前短打的「歷史 edge」仍以既有日線隔日代理作小權重確認，尚未完成真正分 K 歷史 walk-forward 回測。
- GitHub Actions 不是低延遲交易系統；排程可能延遲。
- 歷史回測不代表未來績效，且股票池仍可能存在 current-universe 選擇偏誤。
